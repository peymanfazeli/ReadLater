# SETUP.md

## Scope
This setup is intentionally project-local. Do not alter shared or parent-level configuration.

## Before creating the project
Record versions in the project README or setup log:
- Node.js
- package manager
- Java/JDK
- Android SDK and build tools
- React Native version
- Android Gradle Plugin version generated by the chosen template

Use the official React Native CLI template compatible with the selected environment. Do not manually copy Gradle files from another project.

## Suggested initial sequence
1. Create an empty, dedicated `badabekhoon` directory.
2. Confirm the current working directory is the project root.
3. Initialize the React Native CLI project in that directory.
4. Run the default Android debug build before adding features.
5. Commit the clean baseline.
6. Add application code only after the baseline build succeeds.

## Safety checks
Before any write:
- print/inspect the absolute project root
- verify the destination is a descendant of that root
- do not use parent directories for generated artifacts
- keep `android/local.properties`, keystores, and secrets ignored

## Baseline commands
Use the package manager selected for the project. Typical commands may include:
- install dependencies
- typecheck
- lint
- unit tests
- Android debug build

The exact commands must be recorded after project initialization rather than guessed.
